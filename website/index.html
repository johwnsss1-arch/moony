FAQ

Questions people ask.

Is Moony safe?

Yes. You sign in on Roblox's own login page, Moony never sees your password, and the whole app is open source so anyone can check it. Only download Moony from this site or the GitHub releases page.

Can I get banned for using it?

Moony doesn't inject into the game or give you any advantage. It launches Roblox the normal way and uses settings Roblox supports. It isn't a cheat or an exploit.

Why does Windows say "Windows protected your PC"?

New apps without a long download history get this warning. Click More info, then Run anyway. You can check the source on GitHub first if you want.

Does it cost anything?

No. Moony is free and always will be.

Is Moony made by Roblox?

No. Moony is a fan-made project and isn't affiliated with or endorsed by Roblox Corporation.

How do I suggest a feature or report a bug?

Use the feedback button in Moony's title bar, or post in our Discord.
